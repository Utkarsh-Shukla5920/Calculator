# My Calculator

This is a calculator I made using HTML, CSS and JavaScript while learning web development.

## About the Project

The calculator can perform basic mathematical calculations. I also added a history section to see previous calculations.

## Features

- Addition, subtraction, multiplication and division
- Percentage calculations
- Clear and delete buttons
- Calculation history in a bulleted list
- Keyboard support for entering numbers and calculating answers
- Simple design with my own color choices

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

While making this project, I practised connecting HTML, CSS and JavaScript. I also learned how to handle button clicks, display calculation history and add keyboard controls.

## Future Improvements

- Add a clear history option.
- Improve the layout for mobile screens.
- Add more calculator functions.
